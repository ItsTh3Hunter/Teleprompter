# Teleprompter

A desktop teleprompter application built with WPF and C# (.NET 10), developed for professional presentation use.

## Features

- Mirror effect for teleprompter glass reading
- Adjustable scrolling speed
- Custom font and font size selection
- Custom text and background color
- Physical presentation clicker support (PageDown/PageUp)
- Company logo as background watermark
- Fullscreen teleprompter mode

## How to use

1. Open the app
2. Choose your font, size and scrolling speed
3. Select text and background colors
4. Paste your script in the text area
5. Click **Iniciar Teleprompter**
6. Use your presentation clicker to control the scroll
7. Press **Escape** to exit

## Controls

| Key | Action |
|-----|--------|
| PageDown | Scroll forward |
| PageUp | Scroll backward |
| Escape | Close teleprompter |
